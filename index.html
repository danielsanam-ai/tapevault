STEP 01
드라이브 연결 & 테이프 인식

LTO 드라이브를 연결하면 TapeVault가 자동으로 감지합니다. 드라이브 상태, 테이프 용량, 사용률을 실시간으로 확인할 수 있어요.

  • LTO-4 ~ LTO-9 드라이브 자동 인식
  • 테이프 용량 및 사용률 실시간 표시
  • 드라이브 상태 모니터링 (읽기/쓰기/대기)
  • SAS / Thunderbolt / USB 인터페이스 지원
💡 드라이브가 인식되지 않을 경우 상단의 새로고침 버튼 한 번으로 재스캔됩니다.

STEP 02
프로젝트 구성 & 대기열 등록

방송사, 병원, 기관별로 프로젝트와 폴더를 구성하세요. 파일을 선택해 테이프 기록 대기열에 추가하면 됩니다. 체크섬과 메타데이터는 자동으로 관리됩니다.

  • 계층형 프로젝트/폴더 구조 지원
  • 파일 선택 → 대기열 추가 → 테이프 지정
  • MP4, MOV, MXF, AVI, PDF, ZIP 등 모든 포맷
  • 자동 체크섬 검증으로 데이터 무결성 보장
  • 촬영자, 촬영장소, 담당자 메타데이터 입력
💡 파일을 선택하고 테이프기록 대기에 추가 버튼 하나면 끝. 복잡한 설정 없이 바로 시작할 수 있어요.
STEP 03
테이프 기록 & 실시간 모니터링

기록 시작 버튼 하나로 대기열의 파일들이 LTO 테이프에 순차 기록됩니다. 진행 상황을 실시간으로 확인하고, 완료 후 자동 검증이 이루어집니다.

  • 대기열 파일 순차 자동 기록
  • 파일별 진행률 및 속도 실시간 표시
  • 기록 완료 후 자동 베리파이(Verify)
  • 오류 발생 시 즉시 알림 및 재시도
  • 기록 완료 리포트 자동 저장
💡 LTO-7 기준 평균 기록 속도 300 MB/s. 100GB 파일도 약 6분이면 완료됩니다.

STEP 04
즉시 검색 & 파일 꺼내기

파일명, 날짜, 메타데이터로 전체 테이프 라이브러리를 즉시 검색합니다. 어느 테이프에 있든 30초 안에 찾아서 꺼낼 수 있어요.

  • 파일명 · 날짜 · 해상도 · 담당자로 검색
  • 14개 테이프 전체를 0.03초 만에 검색
  • 검색 결과에서 바로 꺼내기(Recall) 실행
  • 어느 테이프에 있는지 자동 표시
  • 썸네일로 파일 내용 미리 확인
💡 테이프 14개, 71개 파일 전체를 0.03초에 검색. 수작업으로 테이프 라벨을 뒤지던 시간을 없애드립니다.

FAQ
Frequently asked questions
Which LTO drive generations does TapeVault support?
TapeVault supports LTO-4 through LTO-9. Single-drive in all plans; multi-drive in Pro and Enterprise.
Does TapeVault require an internet connection?
No. TapeVault is fully offline-capable after initial license activation. Ideal for air-gapped environments.
What file formats are supported?
Any file your OS can read — MP4, MOV, MXF, AVI, PDF, ZIP, JPG, PNG and more. Video files get automatic thumbnail generation.
