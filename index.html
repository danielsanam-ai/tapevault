STEP 02
Project Setup & Queue Management

Organize projects and folders by client, department, or date. Select files, add them to the tape write queue, and assign to a specific tape. Checksums and metadata are managed automatically.

  • Hierarchical project and folder structure
  • Select files → Add to queue → Assign tape
  • MP4, MOV, MXF, AVI, PDF, ZIP and any file format
  • Automatic checksum verification for data integrity
  • Cameraman, location, and owner metadata fields
💡 Select files and click Add to Tape Queue. No complex configuration — start archiving immediately.
STEP 03
Tape Writing & Real-time Monitoring

One click starts writing all queued files to LTO tape in sequence. Monitor progress in real time — automatic verification runs after each file completes.

  • Sequential automatic writing of queued files
  • Per-file progress and speed displayed in real time
  • Automatic verify pass after each write completes
  • Instant alert on error with automatic retry
  • Write completion report saved automatically
💡 Average write speed 300 MB/s on LTO-7. A 100 GB file completes in around 6 minutes.

FAQ
Frequently asked questions
Which LTO drive generations does TapeVault support?
TapeVault supports LTO-4 through LTO-9. Single-drive in all plans; multi-drive in Pro and Enterprise.
Does TapeVault require an internet connection?
No. TapeVault is fully offline-capable after initial license activation. Ideal for air-gapped environments.
What file formats are supported?
Any file your OS can read — MP4, MOV, MXF, AVI, PDF, ZIP, JPG, PNG and more. Video files get automatic thumbnail generation.
