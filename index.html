How it works
From shoot to shelf — and back

Six steps cover the whole archive workflow. The screens below are the real TapeVault 1.2.9 interface, shown with sample project data.

STEP 01
Prepare a tape
in a few clicks
Insert a new tape and TapeVault offers to format it as LTFS. Give it a volume name and it is registered in your catalog. From then on the tape is recognized automatically whenever you insert it.
  • LTFS format — readable on Windows, macOS and Linux
  • LTO-5 to LTO-9 drives detected automatically
  • Tape name, capacity and free space shown in the top bar
  • Two drives? Each drive gets its own status row
💡 The catalog remembers every tape, so you can browse its contents even when the tape is on the shelf.
▲ New tape registration
STEP 02
Drag folders in.
Your structure is kept.
Drop shoot folders from Explorer or Finder onto the tree. The whole subfolder structure is recreated, and that same structure is what gets written to tape. Thumbnails for video and images are generated automatically.
  • Drag and drop folders or files — subfolders included
  • Unlimited folder depth; rename, move or add any time
  • Hidden and zero-byte files are skipped automatically
  • Right-click menu for every folder action
💡 Organize by year, project and camera roll once — everyone on the team finds files the same way.
▲ Folder tree and right-click menu
STEP 03
Write to tape.
Every file verified.
Select files or whole folders, add them to the write queue and press start. Each file is written, read back from the tape and compared by checksum — only verified files are marked done.
  • xxHash64 + MD5 calculated while copying
  • Read-back verification of every file on tape
  • Progress with speed and time remaining
  • Optional second copy to another tape, or two drives at once
💡 If the app is closed or the connection drops mid-write, TapeVault resumes with the remaining files next time.
▲ Write queue
STEP 04
Find any file
without loading a tape
Browse thumbnails or type in the search box — the catalog covers every tape you have written. Click a file to see its resolution, codec, size, checksum and exactly which tape and path it is on.
  • Thumbnail cards or a compact list view
  • Search across all tapes at once
  • Tape name and path shown for every file
  • Your own notes: shoot date, location, owner
💡 The badge on each card shows the tape name once the file is safely on tape; gray means it is still waiting.
▲ File cards and the info panel
STEP 05
Restore files or
whole folders, verified
Pick the files — or right-click a folder to restore it with all its subfolders. TapeVault tells you which tape to insert, copies the files back in their original structure and verifies them against the checksums recorded at write time.
  • Restore single files, selections or entire folders
  • Tells you which tape to insert
  • Checksum verification after restore
  • Files spread over several tapes are restored tape by tape
💡 Restoring a whole project years later is one right-click — no need to remember which tape holds what.
▲ Restore dialog
STEP 06
Reports and
delivery manifests
Export a CSV file list of any folder with size, tape, checksum and media details for clients or audits. For studio deliveries, TapeVault can write MD5 manifests or ASC MHL files to the tape automatically.
  • File list export (CSV, subfolders included)
  • MD5 manifest written to tape for studio delivery
  • ASC MHL v2.0 per roll
  • Catalog and error reports
💡 Hand over the tape with a file list and manifest the receiving side can verify on their own.
▲ List view with tape status

FAQ
Questions before buying?
Does TapeVault work without an internet connection?+
Yes. TapeVault is fully offline after the initial license activation. No ongoing internet connection is required. This makes it ideal for air-gapped environments in broadcast, defense, and medical sectors.
What happens to my data when my license expires?+
Your archived data on tape is always yours — it's stored in standard LTFS format, which is readable by any LTFS-compatible software. After a license expires, TapeVault asks you to renew before it can be used again; nothing on your tapes or in the catalog stored on your computer is deleted.
Is there automatic renewal?+
No. There is no automatic renewal. TapeVault does not store credit card details. When your license expires, you can renew manually at any time from the purchase page.
Which LTO generations are supported?+
TapeVault supports LTO-5 through LTO-9 drives. LTO-10 support is planned. Both standalone drives and autoloaders (AUTOLOADER plan) are supported.
What is the difference between Starter and AutoLoader?+
Starter is designed for standalone LTO drives (up to 2 drives). AutoLoader removes the drive limit and adds control of tape autoloaders and libraries. Library control is currently available on Windows; on macOS, AutoLoader removes the drive limit only.
Can I install TapeVault on multiple computers?+
A license is tied to the computer it was activated on. How many computers you can register depends on the licenses you bought. To move a license to a different computer, contact support@tapevault.net.
